# Edit model API reference

The edit model is the dependency-free authority for project state, exact timeline time, revisions,
and undoable mutations.

- [Model types](model.md) describes authoritative project, track, clip, marker, caption, title, and
  transition state.
- [Edit commands](commands.md) describes every typed mutation, including batch, linked, trim,
  track, and gap contracts.
- [TimelineEditor](TimelineEditor.md) describes revisions, atomic apply/batch, history, snapshots,
  and derived gaps.
- [Exact snapping](snapping.md) describes candidates, exclusions, and deterministic tie ordering.
- [Timeline semantics](../../../docs/reference/timeline-semantics.md) documents cross-command
  invariants.
