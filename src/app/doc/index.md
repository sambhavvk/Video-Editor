# Application orchestration reference

The `app` module is the Qt composition root. It converts presentation intent into revision-checked
edit commands and connects immutable revisions to media, render, audio, worker, cache, and export
services.

- [EditorController](EditorController.md) — lifecycle, local transcription, caption review, and
  asynchronous boundary contracts.
